# scoop-bucket

My Scoop Bucket

## Setup

```
scoop bucket add siakhooi https://github.com/siakhooi/scoop-bucket.git
```

## Applications
- [json2table](https://github.com/siakhooi/json2table) - Convert JSON to table output
- [picsum](https://github.com/siakhooi/picsum) - CLI client for picsum.photos

## Usage
```
scoop install json2table
scoop install picsum
```
